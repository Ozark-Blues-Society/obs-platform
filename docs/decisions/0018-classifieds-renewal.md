# 0018 — Renewing an unchanged classifieds listing needs no new review

Status: Accepted (Parker, 2026-11-27, Q-20261127-221243-29891, option A). Confirmed on Discord 2026-11-28.

## Decision

- A poster renews from My listings (the reminder email links there). The unchanged listing stays up for
  60 days from the renewal day and moves back to the top of the classifieds.
- Renew shows from the reminder (5 days before the listing comes down), and on a listing that has
  already come down.
- Renewing needs a current membership, like posting.
- Any edit to a listing still goes to the moderator (Kelly).
