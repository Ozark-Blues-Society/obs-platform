🧰 Nothing to patch

No plugins or themes to update. Logins, payments and email run on services whose whole job is keeping them secure.

🏠 The Society owns it

The code is in the Society's GitHub account, and every service account is in the Society's name. Any web developer can pick it up.

💵 Low, predictable costs

About $30–70 a month, plus standard card fees. No per-member pricing.
