# Pages

Pages are the website's standalone pages, such as About & Volunteer, a band spotlight or the venue
directory. Events, blog posts and sponsors have their own sections in the Studio. Open **Pages**
and select **+** (Create) to add one.

## The basics

- **Page title**: the main heading. Browser tabs and search results show it too.
- **Web address**: press **Generate** to make it from the title. The page lives at
  `/<web address>`, for example `/about-and-volunteer`. Use lowercase letters, numbers and
  hyphens. A few addresses belong to other parts of the site (such as `events`, `blog` or
  `studio`), and the Studio tells you if you pick one. Changing the address later breaks links
  people have saved, so settle it before you share the page.
- **Template**: the page's layout.
  - **Standard page** suits most pages.
  - **Directory** is for lists, such as the venue directory.
  - **Band Spotlight** is for band and musician profiles.
  - **Promo Feature** is for campaigns, such as a call for bands.
- **Who can see this page?**: see [Who can see it](content-studio.md#who-can-see-it).
- **Show in menu**: where a link to the page appears. **Main menu** puts it in the top menu.
  **Under Events**, **Under About** and **Under Member Resources** put it inside that part of the
  top menu. **Footer** puts it with the links at the bottom of every page. Leave it on **Don't add
  to a menu** for pages you link to from somewhere else, such as a button.

## Page blocks

A page is a list of blocks, top to bottom. Select **Add item** to add one, drag the handle to move
it, and use its menu to remove it. Each block keeps the Society's design, so you fill in words and
photos and the layout looks after itself.

| Block                          | What it shows                                                                                                              |
| ------------------------------ | -------------------------------------------------------------------------------------------------------------------------- |
| Hero photo and headline        | A wide photo with a big headline, a line of text and an optional button.                                                   |
| Text                           | Formatted text, written in the Studio or pasted from Word or Google Docs. It can hold photos and videos too.               |
| Photo                          | One photo with an optional caption.                                                                                        |
| Video or Bandcamp player       | A YouTube or Vimeo video, or a Bandcamp player (see below).                                                                |
| Upcoming events (fills itself) | The next events from the calendar. Choose how many.                                                                        |
| Sponsor logos (fills itself)   | Current sponsors' logos. Leave **Which sponsors** empty for all of them, or pick some, such as an event's own sponsors.    |
| Table                          | A table you type, or the venue directory (see [Events and venues](events-and-venues.md#the-venue-directory)).              |
| Button                         | A button that links to a page, post or event in the Studio, or to a web address.                                           |
| Pull quote                     | A highlighted quote with the name of who said it.                                                                          |
| Form                           | A form people fill in on the website. Today that's the volunteer sign-up, which goes to the volunteer coordinator.         |

**Bandcamp players:** on the album's Bandcamp page, choose **Share / Embed**, pick a player style,
and copy the code. Inside it is a link that starts with `https://bandcamp.com/EmbeddedPlayer/`:
paste just that link into the block.

**Tables you type:** add the column headings first, then add rows. Each row needs one cell for
every column, in the same order as the headings.
