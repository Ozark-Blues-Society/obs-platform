# Members-only files

Some files are for members only: board minutes, a booking guide, a recording of a workshop. Keep
them on the website's **Members-only files** screen, never in the Content Studio. Anyone who has the
address of a file uploaded to the Studio can open it, even from a members-only page.

Editors and administrators can use the screen. Open it from the admin menu, or by adding
`/admin/files` to the website's address, for example `https://<the Society's website>/admin/files`,
and sign in if the website asks. Anyone else who opens it is told that only editors and
administrators can manage members-only files.

## Uploading a file

1. Under **Upload a file**, choose the file. It can be up to 50 MB.
2. Give it a **Name** members will recognize, for example "November board minutes".
3. Choose **Who can download it**:
   - **Every member, at any level**, or
   - **Only some membership levels**, then tick the levels (Individual, Band, Business, Sponsor).
4. Select **Upload file**.

The screen confirms it and shows the file's **code**, a long line of letters, numbers and dashes.
Select **Copy code** next to it. Every file in the list under **Files** has its code and a
**Copy code** button too.

## Adding it to a page, post or event

1. Open the page, post or event in the Content Studio.
2. Under **Members-only files**, add an item.
3. Type the **Link text**, for example "November board minutes (PDF)".
4. Paste the **File code**. The Studio checks that it looks like a code from the files screen.
5. Publish.

The page shows the link under **Files for members**, marked "Members only".

## Who gets the file

- A visitor who selects the link is asked to sign in first. Then the download starts.
- A member whose membership allows it gets the file straight away.
- A member whose membership has ended is asked to renew, and a member at a level that can't have
  the file is told it isn't available to them.

Who can download a file is set on the files screen, not in the Studio, so it doesn't have to match
the page. A page for everyone can offer a file for members only, and visitors see its link and a
prompt to sign in. A members-only page hides its files from visitors along with the rest of the
page.

Every download goes through the website, which checks the member first. The address the file
finally comes from works for one minute, so passing it on doesn't help anyone. A member can still
share the file itself once they have it, so don't upload anything they shouldn't keep.

## Removing a file

Under **Files**, select **Remove** next to it and confirm. Nobody can download it after that, and
links to it on the website stop working, so take the link out of the page, post or event in the
Studio too.

To replace a file with a new version, upload the new one, put its code in the Studio instead of the
old one, then remove the old file.
