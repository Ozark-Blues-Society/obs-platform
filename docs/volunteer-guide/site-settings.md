# Site settings

**Site settings** is a single document for things that appear across the whole website. It's at
the bottom of the Studio's list. There is only ever one, so it can't be duplicated or deleted. Its
tabs:

- **Footer**: a sentence about the Society, the mailing address, and the public email address and
  phone number shown at the bottom of every page.
- **Social links**: the Society's pages on Facebook, Instagram, YouTube and so on, in the order
  the footer shows them. Each link starts with `https://`.
- **Membership benefits**: the benefits table on the Membership Benefits & Join page. Each row is
  one benefit, with a tick for every membership level that gets it. It starts out as the table the
  board approved. Prices aren't set here: they come from the payment system.
- **Menus**: menu links to things that aren't pages in the Studio, such as another website. Give
  each a label, where it goes (a web address, or a part of this site such as `/events`) and which
  menu it belongs in. Pages add themselves to menus with their own **Show in menu** setting (see
  [Pages](pages.md#how-the-menus-work)). In each menu these links come after the pages, in the
  order you list them here; drag them to reorder.

The footer of every page shows the sentence about the Society, the mailing address, the email
address and phone number (both can be tapped on a phone), and a **Stay in touch** list of the
social links. Anything left empty is simply left out.

Changes go live when you press **Publish**, like everything else in the Studio.
