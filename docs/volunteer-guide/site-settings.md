# Site settings

**Site settings** is a single document for things that appear across the whole website. It's at
the bottom of the Studio's list. There is only ever one, so it can't be duplicated or deleted. Its
tabs:

- **Footer**: a sentence about the Society, the mailing address, and the public email address and
  phone number shown at the bottom of every page.
- **Social links**: the Society's pages on Facebook, Instagram, YouTube and so on, in the order
  the footer shows them. Each link starts with `https://`.
- **Membership benefits**: the benefits table on the Membership Benefits & Join page. Each row is
  one benefit, with a tick for every membership level that gets it. It starts out as the table the
  board approved. Prices aren't set here: they come from the payment system. Members also see the
  benefits of their own level on My Account.
- **Member perks**: the codes members use for their perks, such as the merchandise discount. See
  [Member perk codes](#member-perk-codes) below.
- **Menus**: menu links to things that aren't pages in the Studio, such as another website. Give
  each a label, where it goes (a web address, or a part of this site such as `/events`) and which
  menu it belongs in. Pages add themselves to menus with their own **Show in menu** setting (see
  [Pages](pages.md#how-the-menus-work)). In each menu these links come after the pages, in the
  order you list them here; drag them to reorder.

The footer of every page shows the sentence about the Society, the mailing address, the email
address and phone number (both can be tapped on a phone), and a **Stay in touch** list of the
social links. Anything left empty is simply left out.

## Member perk codes

Some member benefits are handled in person rather than on the website: the merchandise discount,
VIP drawings and giveaways, ticket pre-sales, and the Sponsor discount on paid Society events. For
these, members show or give a perk code, which they find on their **My Account** page.

Each perk code has:

- **Name**: what the code is, for example _Member discount code_ or _Sponsor discount code_.
- **Code**: the code itself, for example _BLUES-MBR-26_. Up to 40 characters.
- **How to use it** (optional): where it works and what it gets, for example _15% off Society
  merchandise at the merch table (not bulk orders)_.
- **Levels that get it**: tick every membership level that gets the code. The board's rules: every
  member gets the member code, and Sponsor members also get the Sponsor code (board decisions §5).

If a code gets a discount on something paid through Zeffy, such as event tickets, create the same
code in Zeffy as well. Zeffy is what applies the discount; Site settings only shows the code to
members.

The codes are for members only. A code shows on My Account to members at the levels ticked, while
their membership is active, and nowhere else on the website. When a membership ends, its codes
disappear from that member's page until they renew.

To change a code, for example at the start of a new year, edit it and press **Publish**. Members see
the new code the next time they open My Account. Tell whoever checks codes at the merch table and
the door when a code changes.

Changes go live when you press **Publish**, like everything else in the Studio.
